Settings

Logger preferences and Sky Sports data connection

Data source

This build uses Sky Sports' football Scores & Fixtures pages as the primary source. Match links point back to Sky Sports match centres for line-up retrieval when available.

Fixture sourceSky Sports
Local savingOn

Connection

A local HTML file may be blocked by browser CORS or a corporate network. The logger queries only the nine supported Sky Sports competition pages. Successful results are cached by date so a temporary network failure cannot wipe the fixture list. No BBC endpoint is used.
